## 一、产品定位

### 一句话定义

```
广州产业AI运营官 = AI产业园运营操作系统

不是 Chatbot，是一支 7×24 小时 AI 产业运营团队。
替代传统：招商/政策/企服/产业研究/风控 5 个团队。
```

### 核心价值主张

| 传统模式 | AI 模式 |
|---------|--------|
| 招商经理手动搜索企业，2 周出一份报告 | 一句话需求，30 秒生成招商方案 |
| 政策咨询需人工翻阅 PDF | RAG 智能匹配，秒级返回 |
| 风险靠经验判断，滞后 3 个月 | 实时多维评分，主动预警 |
| 数据分散在 Excel | 统一 Dashboard，一屏掌控 |
| 决策靠经验 | AI 洞察 + 可解释链路 |

### 目标用户

- **园区管委会/运营方**：掌握全局数据，科学决策
- **招商经理**：AI 辅助找企业、评企业、定策略
- **企业服务人员**：自动化工单 + 智能匹配资源

## 二、比赛策略

### 评委关注点 → 对应设计

| 评委关注 | 项目设计 |
|---------|---------|
| Agent 协作能力 | Supervisor 编排 6 个 Agent，全链路可追踪 |
| 实用价值 | 真实产业园场景，替代 5 个传统岗位 |
| 技术深度 | LangGraph + RAG + pgvector + 评分模型 |
| 可解释性 | Agent Trace 完整展示推理链路 |
| 创新性 | 多 Agent 产业园运营，国内首创 |
| Demo 效果 | 一句话输入 → 30 秒 → 完整招商方案 |

### 制胜点

1. **一句话到完整方案**：输入"帮我找广州机器人产业链企业并评估风险"，30 秒内 Supervisor 编排 IndustryAgent → InvestmentAgent → RiskAgent → PolicyAgent → BIAgent，输出完整招商报告
2. **全链路可解释**：Agent Trace 展示每个决策的数据来源和推理过程
3. **真实场景**：广州产业园区真实需求，非玩具 Demo

## 四、Demo 技术方案

### 真实运行 vs 预录制

| 环节 | 方案 | 原因 |
|------|------|------|
| Supervisor 意图识别 | **真实运行** | 展示 LLM 理解能力 |
| IndustryAgent 产业分析 | **预加载数据** | 保证稳定，避免 LLM 幻觉 |
| InvestmentAgent 企业搜索 | **预加载 Top 5** | 保证速度 |
| RiskAgent 风险评估 | **真实运行** | 评分模型确定性高 |
| PolicyAgent 政策匹配 | **预加载** | 政策数据固定 |
| Agent Trace | **真实数据** | 展示可解释性 |
| Dashboard | **真实数据** | 从 API 实时拉取 |

## 五、页面需求（提交给 React Agent）

### 比赛必需页面

| 页面 | 路由 | 优先级 | 说明 |
|------|------|:---:|------|
| AI 运营中心 | /agent/chat | P0 | 核心对话界面，一句话输入 → Agent 协作 → 结果展示 |
| Agent Trace | /agent/trace/[taskId] | P0 | React Flow 可视化，展示完整推理链路 |
| 园区总览 | /dashboard | P0 | 4 个 KPI 卡片 + 图表 |

| 风险驾驶舱 | /dashboard/risk | P2 | 风险分布 + 预警列表 |

### Demo 专用 UI 要求

1. **Agent 执行动画**：展示 IndustryAgent → InvestmentAgent → RiskAgent → PolicyAgent 的流转动画
2. **实时进度**：显示每个 Agent 的执行状态（思考中/执行中/完成）
3. **Tool Call 展示**：卡片展示 Agent 调用了哪些 Tool
4. **Markdown 渲染**：最终报告以专业 Markdown 格式呈现

## 六、API 需求（提交给 FastAPI Agent）

### 核心 API（P0）

```
POST /api/v1/agent/chat          # 一句话对话入口
GET  /api/v1/agent/task/{id}/trace  # Trace 数据
GET  /api/v1/dashboard/overview  # 总览数据

### Demo API（P1）

```
GET  /api/v1/investment/profile/{id}  # 企业画像
POST /api/v1/risk/analyze            # 风险分析

### WebSocket（P0）

```
WS /api/v1/ws/task/{task_id}   # 实时 Agent 事件推送
```

## 十一、Demo 风险与应对
