## 2. Key Changes

### 2.1 Alembic replaces Base.metadata.create_all()
- `init_db()` now calls `alembic.command.upgrade('head')` instead of SQLAlchemy auto-create
- Async PostgreSQL support via `create_async_engine` + `run_sync`

### 2.2 Password: SHA256 → bcrypt
- `hash_password()` now uses bcrypt with salt
- `verify_password()` detects bcrypt format; falls back to SHA256 for legacy hashes

### 2.3 user_data_scope (park isolation)
- `User.data_scope` field added (default: `"all"`)
- Supports per-park data filtering in future queries
