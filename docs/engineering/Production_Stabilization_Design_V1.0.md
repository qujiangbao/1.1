## 3. ID 生命周期设计

```
conversation_id: 会话级 (多次任务复用)
task_id:         任务级 (每次 chat 新建) → 同时作为 thread_id 和 trace_id
trace_id:        = task_id

config = {
    "configurable": {
        "thread_id": task_id,           # ← 改为 task_id (修复前是 conversation_id)
        "conversation_id": conversation_id,
    }
}
```

修复影响: `agent.py:50` 行，`config["configurable"]["thread_id"]` 从 `conversation_id` 改为 `task_id`。

## 4. LLM 配置设计

移除 `llm_gateway.py` 中所有 `deepseek-chat` 硬编码。Gateway 初始化时从 `get_settings()` 读取 `deepseek_model`。

```python
class LLMGateway:
    def __init__(self):
        s = get_settings()
        self.deepseek_model = s.deepseek_model
        self._available_models = self._detect_available()

    def _models_for_task(self, task_type: str) -> list[str]:
        if task_type == "simple":
            return [self.deepseek_model, "gpt-4o-mini"]
        return [self.deepseek_model]
```
