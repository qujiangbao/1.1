## 一、核心故事线 — "AI 招商经理的一天"

### 故事设定

**主角**：张总，广州某产业园区管委会主任

**痛点**：
- 园区要建机器人产业园，但没有专业团队
- 招商靠人脉，找不到精准企业
- 政策 100+ 份 PDF，不知道企业能享受什么
- 风险靠经验判断，曾有两家企业入驻后资金链断裂

**转折**：园区引入「广州产业AI运营官」

**高潮**：张总打开系统，输入一句话——

> "帮我制定广州机器人产业园招商方案"

30 秒后，一份包含产业分析、企业推荐、风险评估、政策匹配的完整方案呈现在眼前。

**结局**：张总拿着 AI 生成的方案去汇报，成功获批 5000 万园区建设资金。

### 故事主题

```
传统招商 2 周 → AI 协作 30 秒
靠人脉判断 → 数据驱动决策
黑盒 AI → 全链路可解释
```

## 二、AI 运营官的一天工作场景

### 08:00 — 自动生成园区运营日报

```
BIAgent 自动执行：
├── 园区指标：企业 12580 家，本月新增 45 家

├── 风险预警：3 家企业风险上升，建议关注
└── AI 洞察：机器人产业热度↑15%，建议加大招商力度
```

**展示效果**：Dashboard 自动刷新，KPI 卡片动态更新

### 09:30 — 发现招商机会

```
用户输入："广州机器人产业链有什么缺口？"

IndustryAgent 执行：
├── 产业链分析：上游传感器依赖进口，缺口 40%
├── 趋势评分：85 分（战略产业）
└── 招商方向：核心零部件 > 系统集成 > 应用场景
```

### 10:30 — AI 精准招商

```
用户输入："帮我找做机器人传感器的企业"

InvestmentAgent 执行：
├── 搜索 45 家企业 → 画像分析 → 评分排序
├── Top 5：智行机器人(92) / 拓斯达(88) / 优必选(85)...
└── 生成招商策略：优先接触 Top 3，准备政策礼包
```

### 14:00 — 风险预警触发

```
RiskAgent 自动检测：
├── 某企业融资 6 个月未更新 → 财务风险 ↑
├── 负面舆情增加 → 舆情风险 ↑
└── 推送预警：建议管委会主动走访
```

### 15:30 — 政策精准匹配

```
PolicyAgent 执行：
├── 匹配 8 条适用政策
├── 广州市人工智能扶持办法：匹配度 95%
└── 自动生成申请材料清单
```

### 17:00 — 运营决策报告

```
Supervisor 汇总全天数据：
├── 招商：发现 45 家企业，推荐 5 家优先接触
├── 风险：3 家需关注，1 家建议走访
├── 政策：为 12 家企业匹配了政策
└── 建议：机器人传感器方向值得重点突破
```

## 三、Demo 用户流程（核心展示）

### 完整执行链路

```
用户输入
  "帮我制定广州机器人产业园招商方案"
      |
      v
Supervisor 意图识别 (DeepSeek LLM)
  识别：compound [产业分析, 企业搜索, 风险评估, 政策匹配]
  置信度：0.92
      |
      v
Task Planner 生成任务 DAG
  Task 1: IndustryAgent → 产业趋势分析 [无依赖]
  Task 2: InvestmentAgent → 企业搜索+评分 [依赖 Task 1]
  Task 3: RiskAgent → 批量风险评估 [并行, 依赖 Task 2]
  Task 4: PolicyAgent → 政策匹配 [并行, 依赖 Task 2]
  Task 5: BIAgent → Dashboard 数据 [依赖全部]
      |
      v
Agent 路由执行
  IndustryAgent (2.5s) → InvestmentAgent (3.2s)
  → RiskAgent (1.8s) + PolicyAgent (1.5s) [并行]
  → BIAgent (0.8s)
      |
      v
Result Aggregator (DeepSeek LLM)
  聚合 5 个 Agent 结果 → 生成综合报告
      |
      v
最终输出：招商策略报告
  ├── 产业趋势分析
  ├── Top 5 企业推荐（含评分+理由）
  ├── 风险评估
  ├── 政策匹配建议
  └── 招商行动计划
```

### 用户可见的关键时刻

| 时刻 | 画面 | 效果 |
|------|------|------|
| t=0s | 用户输入一句话 | 自然语言，无结构化 |
| t=2s | Supervisor 识别意图 | 右侧面板显示"AI运营总经理：分析中..." |
| t=5s | IndustryAgent 完成 | 显示"产业趋势：机器人 85分（战略产业）" |
| t=10s | InvestmentAgent 完成 | 显示"发现 45 家企业，Top 5 推荐" |
| t=15s | RiskAgent + PolicyAgent 并行完成 | 风险评分 + 8条政策匹配 |
| t=20s | Supervisor 聚合 | "生成综合报告中..." |
| t=25s | 报告输出 | Markdown 格式招商策略方案 |
| t=30s | 完成 | 可点击 Trace 查看完整决策链 |

## 七、评委评分优化

### 按照 5 个维度逐项设计

| 维度 | 展示内容 | 具体呈现 |
|------|---------|---------|
| **任务完成度** | 一句话输入→完整方案输出 | 30秒内产出含产业分析+企业推荐+风险评估+政策匹配的报告 |
| **可靠性** | LLM Gateway fallback | 现场演示：DeepSeek 主模型，GPT-4o 备用，关键词兜底 |
| **经济性** | Token 成本对比 | 展示单次任务成本 < ¥0.1，对比人工 ¥500/天 |
| **安全性** | Human Approval + 权限 | 高风险操作需要人工确认，Agent 无权直接删数据 |
| **产品化** | Dashboard + 多租户 | 展示完整产品界面，而非 Demo 玩具 |

### 加分项设计

| 加分项 | 实现方式 |
|--------|---------|
| 可解释 AI | Agent Trace 完整决策链 |
| 多 Agent 协作 | 6 个 Agent 卡片 + 状态动画 |
| 垂直行业深度 | 广州机器人产业园真实场景 |
| 实时效果 | 30 秒内完成，非预录制 |
