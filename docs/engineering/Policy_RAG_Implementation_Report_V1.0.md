## 2. 数据库变化

### 新增表

```sql
policy_documents (
    id SERIAL PK,
    policy_id VARCHAR(50) FK → policy,
    filename, file_format, file_hash, file_size,
    page_count, raw_text, parse_status, parse_error,
    created_at, updated_at
)

policy_chunks (
    id SERIAL PK,
    chunk_id VARCHAR(100) UNIQUE,
    policy_id VARCHAR(50) FK → policy,
    document_id INTEGER FK → policy_documents,
    chunk_index, content, content_hash, token_count,
    metadata JSONB,
    created_at
)
-- 注: embedding 列为 pgvector vector(1536)，需启用 pgvector 后由数据库管理
```
