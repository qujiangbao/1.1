# 广州产业园政策同步使用说明

## 已配置的政策源

- 广州市发展和改革委员会规范性文件
- 广州市工业和信息化局政策原文
- 广州市科学技术局政策法规文件
- 广州市商务局扶持政策
- 黄埔区/广州开发区区部门规范性文件
- 黄埔区政府/广州开发区管委会规范性文件

所有来源都在广州政府官方域名白名单内。来源配置文件为：

`D:\crawl4ai-tools\guangzhou_policy_sources.json`

## 一次更新

在 PowerShell 中运行：

```powershell
cd D:\industrial-park-v1.1
.\refresh-guangzhou-policies.ps1
```

默认扫描每个来源最近 3 页，增量更新项目政策缓存和 Policy Agent catalog。
7 天内已经成功抓取的正文不会重复下载，但列表页仍会检查新政策。

## 持续更新

双击：

`D:\industrial-park-v1.1\watch-guangzhou-policies.bat`

脚本默认每 30 分钟检查一次。按 `Ctrl+C` 停止。

也可以在 PowerShell 中指定间隔：

```powershell
.\refresh-guangzhou-policies.ps1 -Watch -IntervalMinutes 60
```

为保护政府网站，轮询间隔不能低于 15 分钟，详情抓取并发不能超过 3。

## 常用参数

```powershell
# 每个来源扫描最近 5 页
.\refresh-guangzhou-policies.ps1 -Pages 5

# 强制刷新已缓存正文
.\refresh-guangzhou-policies.ps1 -Force

# 更新文件后，使用真实 OpenAI embedding 导入 PostgreSQL/pgvector
.\refresh-guangzhou-policies.ps1 -ImportPgvector
```

`-ImportPgvector` 需要项目 `.env` 已配置：

- `DATABASE_ENABLED=true`
- 可连接的 `DATABASE_URL`
- `POLICY_EMBEDDING_PROVIDER=openai`
- 真实的 `OPENAI_API_KEY`

默认运行不会调用 OpenAI，也不会生成 mock 向量。

## 数据位置

- Markdown、索引：`backend\data\policies_gz_gov`
- Policy Agent catalog：`backend\data\policies_gz_gov\_catalog.json`
- 爬虫：`D:\crawl4ai-tools\gz_gov_crawler.py`

爬虫会保存权威来源原文。黄埔区综合栏目中与产业园无关的教育、河道等文件会
标记为 `relevant=false`，保留用于审计，但不会进入 Policy Agent catalog。

## 正常完成标志

控制台应出现：

```text
Policy cache and catalog are ready
```

同时报告中的 `source_errors` 应为 `{}`，`failed` 应为 `0`。
如果某个来源暂时不可用，已有成功缓存不会被删除，下次轮询会再次尝试。
